# บทนำ

โครงงาน KU Sriracha Badminton Court Booking Management System เป็นต้นแบบระบบบริหารจัดการและจองสนามแบดมินตัน มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตศรีราชา โดยใช้แนวคิดจากโจทย์ที่ให้มาว่าสถานที่เปิดให้บริการตามตารางการใช้พื้นที่ วันใดมีกิจกรรมอื่นจะปิดการจองพร้อมแสดงกิจกรรม ไม่กล่าวอ้างว่าระบบนี้เป็นระบบทางการของมหาวิทยาลัย

นิสิตสมัครด้วยรหัสนิสิต 10 หลักและรหัสผ่าน แล้วเข้าใช้บัญชีได้ทันทีโดยไม่รออนุมัติ จากนั้นเลือกวันจองตั้งแต่วันนี้ถึง 30 วัน เลือกหนึ่งใน 5 คอร์ดและช่วงเวลา ระบบใช้รหัสนิสิตจากบัญชีที่เข้าสู่ระบบเป็นผู้จองหลักโดยอัตโนมัติ และให้ยืนยันรหัสนิสิตของผู้เล่นอีกคน ระบบตรวจบัญชีผู้สมัคร สถานะเปิดสนาม และป้องกันการจองคอร์ดเดียวกันในช่วงเวลาเดียวกัน แม้มีคำขอพร้อมกัน หลังจองสามารถบันทึกเงินสนับสนุนค่าบำรุงสนามโดยสมัครใจ เว็บไซต์รองรับภาษาไทยและอังกฤษ

วัตถุประสงค์คือสร้างเว็บไซต์ responsive ที่ใช้ได้ทั้งคอมพิวเตอร์และโทรศัพท์ พร้อมประยุกต์ Relational Model, ER Model, Normalization, Data Dictionary, SQL, Views, Functions, Stored Procedures, Triggers, Transactions และ Concurrency Control ใน flow ที่ใช้งานจริง โดยมี Microsoft SQL Server เป็นฐานข้อมูลหลัก

ข้อความนี้เป็นร่างสำหรับปรับตามเอกสารวิชาและ requirement อาจารย์ฉบับจริง ยังไม่มีไฟล์ชีท/Lab ของอาจารย์ใน workspace จึงไม่ยืนยันว่าตรงเกณฑ์ที่ไม่ได้ให้มา
