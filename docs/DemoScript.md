# ลำดับสาธิต 5–8 นาที

## เตรียมก่อนนำเสนอ
เริ่ม `Start-Demo.ps1` แล้วเปิด http://localhost:5080 เตรียม SSMS ที่ฐาน `KU_Sports` และเปิด `database/09_TestQueries.sql` เปิด `docs/DemoCredentials.local.md` บนเครื่องเดโมเท่านั้น (ไฟล์นี้ไม่ส่งเข้า git/รายงาน) เข้าระบบ admin แล้วเพิ่ม Facility Schedule ให้วันที่จะสาธิตเป็นวันเปิดโดยใช้กำหนดการจริง สร้างบัญชีนิสิต 2 บัญชีด้วยรหัส 10 หลักที่ผู้สาธิตกำหนดเอง ตรวจ Court 1 / 19:00 ว่าว่าง

1. หน้าแรกแสดงสถานะสนามวันนี้และกิจกรรมปิด (ถ้ามี) สาธิตสลับไทย/อังกฤษจากปุ่ม EN/ไทย
2. สมัครบัญชีนิสิตด้วย ID 10 หลัก รหัสผ่านอย่างน้อย 10 ตัวอักษร และชื่อ บัญชีเข้าใช้ได้ทันทีโดยไม่รออนุมัติ
3. เปิดจอง เลือกวันที่ที่ต้องการ (วันนี้ถึง 30 วัน) แล้วเลือก Court 1 → 19:00–20:00
4. หน้าแสดงรหัสนิสิตของบัญชีที่ login เป็นผู้จองหลักโดยอัตโนมัติ กรอกรหัสของบัญชีผู้เล่นคนที่สอง ตรวจชื่อ แล้วกดยืนยัน
5. แสดงหน้าสำเร็จและ Booking ID เปิด History และใน SSMS ดู `BOOKINGS` กับ `BOOKING_LOGS` เพื่อชี้ให้เห็น audit จาก trigger
6. ในอีก session ลองจอง Court 1 / วัน / เวลาเดิม ระบบปฏิเสธเมื่อ slot ไม่ว่าง; concurrency test ยิงสองคำขอพร้อมกันและคาดหวังผล 200 หนึ่งรายการ + 409 หนึ่งรายการ
7. ผู้จองเลือกสนับสนุน 50 บาท หรือข้ามได้ (เป็นข้อมูลจำลอง ไม่โอนเงินจริง)
8. เข้าระบบ Admin เปิดรายงาน เลือกช่วงวันที่จองนั้น แล้วชี้จำนวน booking จำนวนคอร์ดที่ใช้ จำนวนยกเลิก และยอด/จำนวนทิปที่รวมตามวันที่จอง
9. Admin เปลี่ยนตารางของวันที่เลือกเป็นปิดพร้อมชื่อกิจกรรม จากนั้นกลับหน้าจองให้เห็น CLOSED และ booking ปฏิเสธ แล้วคืนเป็นเปิด
10. ยกเลิกรายการจาก History/Admin แล้วดูสถานะ CANCELLED และ audit log โดยไม่ลบแถวถาวร

## อธิบาย concurrency
“การตรวจว่างหน้าเว็บเป็นเพียงการแสดงผล Stored Procedure ใช้ transaction และ range lock ร่วมกับ unique index เพื่อให้ Court + Date + Slot มีรายการ BOOKED ได้เพียงหนึ่งรายการ แม้มีคำขอยืนยันพร้อมกัน”

## ทดสอบจริงกับ SQL Server
เริ่ม server ก่อน แล้วรัน `node tests/integration.mjs` จากโฟลเดอร์โปรเจกต์ การทดสอบสร้างบัญชี/booking ที่ใช้ ID แบบสุ่ม และยกเลิกรายการที่สร้างเพื่อคืน slot; audit กับ donation คงอยู่เพื่อรักษาประวัติ ถ้าทิปมีอยู่ก่อนแล้ว รายงานทดสอบตรวจการเปลี่ยนแปลงเทียบกับยอดตั้งต้น
